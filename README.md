# AbhayaPath 
> **Incentive and Penalty Compliance System for Emergency Corridor To create Fearless Path For Smart India 
## 📌Problem Statement 
Emergency medical response time/Organ Donation service and Patient treatment on time in India suffer significantly due to urban traffic congestion and many other type of congestion like rally. Traditional system exist but lack because of more security concern and are slow to deploy and are based on fixed traffic range.
## 🚀Key Features
- **Dual User Category:** Our system includes both private vehicle and ambulance. We believe that "ambulance are not defined by sirens on them but by patient inside". Including private vehicle might be a risky solution but our post verification procedure makes it secure.Also through real life solution like PELICAN LIGHTS(lights control by push button) which are in many cities we believe that government allow citizen to control light but in mannered way.
- **VAHAN DATABASE INTEGRATION:** Real time vehicle information gathering and OTP verification via official registration record.
- **AI emergency file verifier:** Once the private vehicle reach it's destination i.e hospital a column will appear of uploading file in which file has to be uploaded under limited time. Once a user will upload file our ai will check whether the user has uploaded real and authentic file or not.If the file is not authenticate then it will attract penalty under BNS SECTION 336/SECTION 340.
- **App integration with route planner and security software:** Our app will be integrated with real time navigation app not google maps because of security concern but will integrated with software like MapsMyIndia(Mappls) and ISRO NavIC to have real time location of vehicle.Also to decrease risk of cyber attack MQTT TLS ENCRYPTION USED.
- **Unfair Challan Protector:** Our app will also act as unfair challan protector.In cities like Chandigarh there are AI camera at traffic light junction that penalise e-challan.When ambulance arrives vehicle near the junction front vehicles have to jump the light which penalise e challan for jumping light.
